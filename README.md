# PM2.5 Explorer

ระบบสำรวจคุณภาพอากาศ PM2.5 ของประเทศไทย (รายวิชา 1145100 Data Science Toolbox)

## โครงสร้างโครงการ
- `src/` — สคริปต์สำหรับดึงและจัดการข้อมูล
- `notebooks/` — Jupyter Notebook สำหรับสำรวจข้อมูล (EDA)
- `app/` — แดชบอร์ด Streamlit

## วิธีติดตั้ง
```bash
uv sync
```
(หรือหากใช้ conda: `conda env create -f environment.yml`)
